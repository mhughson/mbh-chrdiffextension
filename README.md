# NES CHR ROM Viewer and Diff Extension for VSCode

This extension add CHR ROM (*.chr) viewer support to VSCode. With the extension installed, when you view a *.chr file in the explorer view, you will get a preview of the CHR ROM as a 4 color image.

Additionally, if you view the CHR ROM (*.chr) file in Source Control, you will get a view of "before" and "after" allowing you to see what has changed between commits, or in the pending commit.

## Status

Currently very early in development, and likely unstable.
